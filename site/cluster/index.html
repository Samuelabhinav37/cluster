Questions.

Does Cluster read my email?

It reads who sent it, the subject and the date. It opens a message only to check the links in one that looks like a scam.

Where does my mail go?

From Gmail to Chrome, on your computer. Cluster keeps no copy on any server.

Can I undo?

Yes. Cluster moves mail to a label or to Trash, never deletes it for good. Gmail keeps Trash for 30 days.

Does it sort when Chrome is closed?

Yes. Cluster sets up Gmail filters, so new mail is sorted as it arrives.
