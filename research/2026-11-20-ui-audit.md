# Cluster UI/UX audit (2026-11-20)

Screens checked in the preview at 1568x758: Dashboard, Cleanup, Labels, Security, Settings, the sidebar read card.
References from Mobbin (web): Stripe settings (Managed Payments, Revenue Recognition), Juicebox's sidebar
"Getting Started" progress card, Productboard / Base44 / Stripe / Plausible metric cards, Searchable and Braintrust
for floating assistant buttons.
