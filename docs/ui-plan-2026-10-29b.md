# UI plan, round 2 (2026-10-29)

Combines the approved Home v2 mockup (research/2026-10-29-home-mockup.html, first-read redesign
3186807), the Muzli dashboard study (research/2026-10-29-dashboard-examples-muzli.md) and the
words/icons/extension study (research/2026-10-29-fewer-words-icons-extension.md).

## Rules (all steps)

1. One question per card; every card filled top to bottom, no empty halves.
2. Every number that changes has a comparison chip (↑ 18% / ↓ 12%), not a sentence.
3. Charts: gray history, accent for now; one accent color; red only for scams.
4. Commands 2 to 4 words, verb first; one verb per action everywhere (Trash, Unsubscribe, Mute,
   Archive); never "OK".
5. Icons: filled glyph on a colored squircle = a place; outline Lucide 16px = an action. Never
   both in one list. Icon-only controls get a tooltip.
6. Kai's one sentence is the caption for the page; no other explanation on the page.
