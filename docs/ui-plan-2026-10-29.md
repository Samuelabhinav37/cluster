# UI plan: one job per place, one home per action (2026-10-29)

Combines five pieces of research into one build order:

- `research/2026-10-29-ui-audit.md`: what's broken or confusing on each screen (B, N, per place)
- `research/2026-10-29-options-inventory.md`: every control per place, six problem types T1 to T6
- `research/2026-10-29-how-big-tech-trims-options.md`: how Apple, Microsoft, Google cut options
- `research/2026-10-29-dashboards-and-option-labels.md`: dashboards, and stacked option rows
- `research/2026-10-29-one-row-mockup.html`: backlog 5.3 + 5.4 mockup (awaiting approval)

## The rules every step follows

From the research, written so a test can check most of them.

1. **One task sentence per place.** Every control on a place serves that sentence; anything else
   moves to its own home or goes (Microsoft IUI).
2. **Each action has one home.** Other places show a count and link there. A ⋯ menu may repeat a
   row's own actions, never add new ones (Apple context menus, Material menus).
3. **One primary button per screen** (Apple toolbars, Fluent).
4. **Options are rows:** icon, name, one gray line, one control on the right. Never inline in a
   sentence. A switch only in a row (Apple toggles, GOV.UK, Material list item).
5. **Every control names itself.** No unlabeled switch, no jargon.
6. **Two levels of hiding at most, one "More" per place** (NN/g, Apple disclosure controls).
7. **The same sender has the same row and the same number everywhere** (backlog 5.3).
8. **Dashboards state the message in words, show amounts as bars, and hide empty charts**
   (NN/g dashboards, Apple charts).

## Task sentences (proposed)

| Place | Task sentence | Its one primary action |
|---|---|---|
| Home | See what needs you today | none (cards open places) |
| Senders | Decide what happens to each sender | none (card holds the choice) |
| Clean up | Delete mail you don't need | Trash |
| Stop mail | Stop mail you don't want | Unsubscribe |
| Organize | Choose where each kind of mail goes | Sort my inbox |
| Protect | Keep scams out | Turn on holding / Block |
| Settings | Change how Cluster works | none |

## One home per action (proposed)

| Action | Home | Everywhere else |
|---|---|---|
| Trash a sender's mail, Keep newest N | Clean up | link "N emails · Clean up ›" |
| Unsubscribe, Mute | Stop mail | link |
| Move to a label, timers, rules, Snooze | Organize | link |
| Block, It's fine, Report, Deep scan | Protect | link |
| "This is a person", see addresses, kind | Senders card | — |
| Activity / undo history | Account menu > Activity (one place) | Settings row removed |
| Rescan, accounts | Settings | account menu keeps only Activity and Settings |
| Delete forever | Clean up's Trash confirm ("Skip Trash") | Settings > Advanced removed |
| Setup | First run sheet | Home card and Settings "Setup" row removed |

## Build order

Each step is its own commit, with tests, on a feature branch, unpushed until you say.

### Step 0: broken things (no decisions needed)
- B1 Settings "Add Outlook" clipped. B2 "What Cluster learned" rows collide.
- B3 Kai covers controls on four pages: give `main` bottom padding equal to Kai's height + 24 px
  so the last row always clears it.
- N2 Stop mail counts: one number ("22 can stop in one click"), drop "29 lists".
- N4 Protect: hide "Held so far" count while Holding is off; one number per tile ("3 of 39
  failed", not also "92%").

### Step 1: one row, one key (5.3), from the mockup
Clean up, Details and Stop mail use `profile.companyKey` and the Senders row. Fixes N1. Remove
the "Group companies" switch (grouping is always on). Impostors stay separate with the badge.

### Step 2: one home per action (5.4 + T1)
Apply the table above. Clean up rows: Trash only, ⋯ keeps Trash variants. Clean up's
"Never opened" row: Trash, and a link "Stop them · Stop mail ›". Organize's "Tidy once" goes
(Never opened → Clean up, Newest 3 → Clean up's Keep newest). Senders card: one choice per
sender with links to the home places. Account menu: Activity and Settings only.

### Step 3: Organize, one list (T2, B4, N3)
Merge Sort now, Archive after a while and Custom times into **one list of kinds**: one row per
kind (icon, name, "84 now · about 41 a week"), trailing pop-up with where it goes and when
("Stays in inbox", "Label now", "Label after 1 day", … "Archive after 1 week"). Question above
it: "Where should each kind go?" One "Sort my inbox" button below. "Keep doing this for new mail"
becomes the default with one switch row. Arrive on time stays. Rules stay as one list with
presets at the top of the New rule sheet. Remove "More tools". Guard line moves under the list
as its footer.

### Step 4: Clean up and Stop mail (T5, T6)
Clean up: top list + one "More" holding Keep newest and By domain, flattened to one level (no
category sub-folds). Stop mail: header "22 can stop in one click" + one Unsubscribe all whose
confirm states the count and lists the senders (Apple Mail's titled multi-select menu). Remove
the floating bar's second button. Rename "Outcome" filter to "Show: All / Still sending /
Stopped". Paid subscriptions rows get a gray line that says what to do ("Cancel with Netflix")
or leave the list.

### Step 5: Protect (dashboard rules)
Order: High priority, Holding, then charts. Tiles become a segmented control (Scams / New
senders / Held). "Scams per week" hidden until there's data. "Brands faked" folded into the High
priority rows (already show the brand). One number per tile.

### Step 6: Home, Settings, chrome (T3, T4)
Setup becomes a first-run sheet. Organize tile shows a number like the others ("41 a week could
leave on their own"). Details panel closed by default on Settings and Protect. Settings: drop
Setup, Safety net, Advanced rows (moved by step 2); Show Kai switch styled like the rest. Name
all 13 switches; replace the jargon list from the inventory.

### Step 7: guards so it stays fixed
Extend `wordBudget.dom.test.ts`:
- at most one `.btn-accent-solid` per screen;
- every checkbox/switch has an accessible name;
- no `details` inside a `details` inside a screen deeper than two levels;
- each action label (Unsubscribe, Mute, Trash, Block) appears outside its home place only as a
  link or inside a ⋯ menu;
- lower the control ceilings to the new counts.
