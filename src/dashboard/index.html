Cluster sorts and cleans up mail using only what your inbox already tells it — subjects, senders, dates, and starred/flagged status, never message bodies. Nothing is deleted without you confirming first, and everything runs from your own sign-in.

Athena email security is available for this managed installation. Enabling the connection sends only minimized security evidence to your organization's Athena server. Mailbox cleanup stays local and suspicious mail is never auto-deleted.
